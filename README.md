# YouTube Website Clone

A responsive YouTube website clone built using **HTML, CSS, and JavaScript**.
The project recreates the basic layout and user interactions of YouTube, including the header, search bar, sidebar, video cards, notifications, and profile interactions.

## 🚀 Features

* YouTube-style header and navigation
* Search bar with search button interaction
* Press **Enter** to trigger the search
* Video cards with click interaction
* Hamburger menu to hide/show the sidebar
* Notification button interaction
* Profile picture interaction
* Responsive video grid layout
* YouTube-style sidebar navigation

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling and responsive layout
* **JavaScript** – User interactions and DOM manipulation

## 💻 JavaScript Functionality

JavaScript is used to add interactive features to the website:

* Search button displays the entered search text
* Pressing Enter in the search bar triggers the search
* Clicking a video displays its title
* Hamburger button toggles the sidebar
* Notification button displays a notification message
* Profile picture responds to clicks
